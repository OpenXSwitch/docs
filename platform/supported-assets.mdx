OpenXSwitch **Wallet Infrastructure** supports native blockchain assets across all supported networks by default.

In addition to native assets, **Wallet Infrastructure** supports a growing set of tokens for:

- Deposits
- Withdraws

> Use the `Get Supported tokens with blockchain` endpoint to retrieve the latest supported assets, and chains.
